# 과학 모델

## 계와 단위

열린 계의 교육용 동역학 모델이다. 시간은 시뮬레이션 초, 농도와 양은 상대값, 흐름은 해당 상대값/초다. ATP 누적량은 합성 플럭스를 적분한 값이다. 시뮬레이션의 포도당 처리량은 시간과 공급 조건에 따라 달라지므로 포도당당 ATP 수율과 구분한다.

## 공급 및 반응 수지

- 해당 과정은 세포질 포도당당 NADH 2, 피루브산 2, 순 ATP 2를 만든다. 2 ATP 투자와 4 ATP 회수는 학습 화면에서 보여준다. 계산은 순반응을 사용한다.
- 바탕질의 피루브산 산화는 피루브산당 아세틸-CoA 1, CO₂ 1, NADH 1이다. TCA는 아세틸기당 CO₂ 2, NADH 3, 효소 결합 FAD 환원 1, ATP/GTP 상당량 1을 산출한다. 8개 반응을 학습 화면에서 따로 살피고, 계산은 전체 회로의 순반응을 사용한다.
- NAD⁺ + NADH 총량은 바탕질과 세포질에서 따로 보존한다. 말산–아스파르트산 셔틀은 바탕질 NADH를 생성하고, 글리세롤 3-인산 셔틀은 Q 경로로 전자를 전달한다. 세포질 NADH는 어느 셔틀에서도 내막을 직접 통과하지 않는다.
- FADH₂는 II에 결합한 환원 상태의 상대 풀이다. 별도 숙신산 공급이 II 경로에 환원당량을 보충한다. 이 공급은 개방 경계를 통해 들어온 숙신산이 같은 양의 푸마르산으로 나가는 별도 가지로 처리한다. TCA 순환 내부 풀과 중복 계산하지 않는다. 글리세롤 3-인산 셔틀 유래 환원 상태는 분리된 Q 풀을 사용한다.
- 젖산 발효에서는 피루브산과 NADH에서 젖산과 NAD⁺가 나온다. 알코올 발효에서는 아세트알데하이드 단계를 거쳐 피루브산당 에탄올, CO₂, NAD⁺가 생성된다. 두 가지 발효는 세포질에서 NAD⁺를 재생한다. 발효 반응에서 ATP 생성은 0이다.
- ATP 1당 ADP와 Pi 각 1을 소비한다. O₂ 공급 중단은 추가 유입을 0으로 설정하고, 초기 용존량은 IV에서 계속 사용된다.

## 전자전달과 구동력

기질 의존 속도 항은 x/(x+K)로 제한한다. I, II와 셔틀 Q의 전자쌍 공급 합계를 III·IV 처리 용량 및 잔류 O₂가 제한한다. 세 진입 흐름은 각 잠재 용량에 비례해서 공통 처리량을 나눈다. 양성자 풀 S에 의한 역압항 max(0, 1 − S/16)을 곱한다. 이 함수는 실험에서 측정한 막의 단일 보편 법칙을 뜻하지 않는다.

한 전자쌍당 I의 펌핑은 4 H⁺, III의 Q 회로 순기여는 4 H⁺, IV의 펌핑은 2 H⁺다. II의 직접 펌핑은 0이다. IV는 전자쌍당 ½ O₂를 소비해 H₂O를 1만큼 생성한다. 물 생성에 소비되는 바탕질 H⁺와 완충·교환 반응은 유효 풀에 따로 적분하지 않는다.

    J_ETC = J_I + J_II + J_Q
    J_pump = 4·J_I + 6·J_ETC
    dS/dt = J_pump − J_synthesis_H − J_leak + J_reverse_H

바탕질 전위에서 막사이공간 전위를 뺀 값을 Δψ로 정의한다. pH 차는 바탕질 pH에서 막사이공간 pH를 뺀 값이다.

    Δψ = −11.4·S 모형 mV
    pH_matrix = 7.20 + 0.032·S
    pH_ims = 7.20 − 0.019·S
    Δp = Δψ − (2.303RT/F)·1000·ΔpH
    |Δp| = −Δp

전위와 pH는 유효 풀을 전하 분리와 완충 계수로 환산한 독출값이다. 입자 수로 농도나 pH를 구하지 않는다. 그림의 막사이공간 입자는 유효 기울기에 연동된다. 두 전위 성분은 같은 풀에서 유도하며 독립적 전하 확산이나 Henderson–Hasselbalch 평형을 풀지 않는다.

## 합성, 억제와 짝풀림

- 합성 반응은 구동력(|Δp|−56 mV)의 양의 부분, ADP, Pi, 합성효소 활성 항에 비례하며, 한 스텝에 사용 가능한 H⁺와 기질량으로 제한된다. 유효 H⁺/ATP는 4이며, 막 수송의 비용을 아우른 교육용 회계값이다. ATP 합성효소 c-ring의 실제 화학양론과 별개다. 로터 각속도는 H⁺ 통과량에서 계산한다.
- 로테논은 I 진입, 시안화물은 IV 처리, 올리고마이신은 F₀ 통과, DNP는 선형 누출항을 바꾼다. 각 억제 비율은 가상의 0–1 상대값이다. 누출은 S와 온도 스케일에 비례한다.
- 산화적 순간 ATP/O는 산화적 ATP 플럭스 ÷ 환원된 산소 원자 플럭스(2 × O₂ 소비율)다. 과도 구간에 저장된 기울기의 영향이 포함된다. 분모가 매우 작으면 표시하지 않는다.
- H⁺ 결합 효율 = 합성효소로 복귀하는 H⁺ ÷ (합성효소 복귀 + 누출). 열 지표 = J_leak × |Δp|/100. 각각 교육용 상대 지표이며 기계 열효율이나 열량으로 환산하지 않는다.
- 기본 실험은 ATP 합성 방향을 계산한다. 고급에서는 따로 준비한 유한 저장 ATP(초기 상대량 4)를 가수분해한다. |Δp|가 56 모형 mV 아래일 때 역방향 H⁺ 흐름이 발생하며, 이 과정에서 ADP·Pi가 증가한다. 전환점, 가역 반응 속도와 ATP 공급·수송 조절은 단순화했다.
- Q₁₀ = 2의 온도 스케일을 공유하며, 실제 효소별 활성 온도·열변성 및 막 상전이의 모형은 포함하지 않는다.

## 수치 방법과 검증 경계

명시적 Euler 적분을 1/120초 고정 간격으로 사용한다. 매 스텝 반응 전 가용량으로 경쟁 플럭스를 제한하며, 부동소수점 하한을 0으로 유지한다. UI는 프레임 타이밍과 별개로 같은 적분 스텝을 사용한다. 브라우저가 장시간 멈췄다가 재개할 때는 프레임당 실제 시간 유입을 0.15초로 제한한다.

원자 기하, 단백질 구조, 전자·양성자의 실제 경로와 생체막 간격은 직접 재현 범위를 벗어난다. 전체 ATP 30–32는 포도당당 교육용 예시다. 32의 예는 기질수준 ATP/GTP 4 + 10 NADH × 2.5 + 2 II 경로 × 1.5다. 글리세롤 3-인산 셔틀에서는 세포질의 두 전자쌍이 Q부터 진입해 같은 회계상 30이 된다. 실제 P/O는 조직·누출·전달 방식·실험 조건에 따라 달라진다.
